# ensemble-trading-bot

**Тема:** курсовая работа по машинному обучению «Ансамблевые методы для анализа доходности биржевых акций и бэктест торговой стратегии». **Предметная область:** биржевые акции.

**Что делает проект.** Проект прогнозирует доходность акций с помощью базовых моделей и их ансамблей, включая бустинги, а затем проверяет полученные сигналы бэктестом торговой стратегии с учётом издержек. На последнем этапе сигналы подключаются к песочнице брокера. Сейчас в репозитории подготовлены окружение и структура проекта; модули в `src/` пока содержат только описание своего назначения.

**Данные.** Котировки выгружаются через библиотеку [yfinance](https://github.com/ranaroussi/yfinance), а технические индикаторы рассчитываются библиотекой [ta](https://github.com/bukosabino/ta). Исходные данные хранятся в формате `.csv` в папке `data/raw/` и входят в репозиторий.

**Запуск.** Понадобится Python 3.13. На macOS для `xgboost` и `lightgbm` также нужен OpenMP: `brew install libomp`.

```bash
git clone https://github.com/Humay65/ensemble-trading-bot.git
cd ensemble-trading-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook notebooks/main.ipynb
```

**Структура проекта.** Анализ, модели и выводы собраны в основном ноутбуке, а код разделён на модули, поэтому `execution.py` можно заменить, не затрагивая остальную часть проекта.

```text
ensemble-trading-bot/
├── README.md
├── requirements.txt
├── .gitignore
├── data/raw/            # исходные данные в .csv
├── notebooks/main.ipynb # основной ноутбук: анализ, модели, выводы
└── src/
    ├── data.py          # выгрузка котировок
    ├── features.py      # технические индикаторы
    ├── models.py        # базовые модели и ансамбли
    ├── backtest.py      # бэктест с издержками
    └── execution.py     # песочница брокера, делается последним
```
